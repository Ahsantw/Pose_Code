# NAFNET

### Requirement
* Python 3.8
* pip install requirement.txt

### Model

* [Model](https://drive.google.com/file/d/14D4V4raNYIOhETfcuuLI3bGLB-OYIv6X/view)

### Sample Command
```
python basicsr/demo.py -opt NAFNet-width64.yml --input_path blurry.jpg --output_path out.png
```
* --input_path: Path to blurry image.
* --output_path: Output path to save clear image.
